# Coin Flip — Google Apps Script

These two files are a complete, free Google Apps Script HTMLService web app.

## Deploy

1. Go to [script.google.com](https://script.google.com/) and create a new project.
2. Replace the default `Code.gs` contents with `Code.gs` from this folder.
3. Add an HTML file named `Index` and paste in `Index.html`.
4. Click **Deploy → New deployment**.
5. Choose **Web app**, select who should have access, and deploy.

The app does not use a database, external APIs, or paid services. Flip history and theme preferences are stored locally in each visitor's browser.
